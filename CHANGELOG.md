# Changelog

## v1.1 - December 2025

### Added
- Text editor (vi command) for creating and editing files
- Directory creation support (mkdir command)
- File loading and execution capability (load command)

### Fixed
- Reboot functionality now works properly
- QEMU configuration adjusted for system restart

### Improved
- Better file system navigation
- More complete shell command set
- Overall system stability

---

## v1.0 - Initial Release

Basic OS functionality with:
- FAT32 file system support
- ATA disk driver
- VGA text mode display
- Keyboard input
- Memory management (heap, paging)
- Shell with basic commands
